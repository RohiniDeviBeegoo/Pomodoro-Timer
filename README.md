# Pomodoro Timer

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/7c94c3f0-dd4c-4fed-a9e3-0fb96eef75f4" />
A custom-built Pomodoro timer with a mechanical dial interface, built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries.

**[Live Demo](https://rohinidevibeegoo.github.io/Pomodoro-Timer/)**

## Features

- Drag the circular dial (or use arrow keys) to set your own focus duration
- Visual progress ring that depletes in sync with a moving handle, like a real kitchen timer unwinding
- Automatically cycles focus sessions into short breaks, with a longer break after every 4 sessions
- Session dots track completed pomodoros
- Soft audio chime on session completion
- Fully keyboard accessible (Space to start/pause, R to reset, arrow keys to adjust duration)
- Responsive layout that works on desktop and mobile

## Built With

- HTML5 (SVG for the dial and progress ring)
- CSS3 (custom properties, gradients, animations)
- Vanilla JavaScript (no external libraries)
- Google Fonts (Cormorant Garamond, IBM Plex Mono)

```bash
cd Pomodoro-Timer
```
